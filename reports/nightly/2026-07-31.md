### Content Engine Pipeline Restoration

**File:** `scripts/nightly-engine.js` (83 insertions, 9 deletions)

#### Root Cause Analysis

The content engine's nightly pipeline stopped running around May 29, 2026 because:
1. The scheduling mechanism (`cron-daemon.js` / `pipeline-loop.js`) was removed during a refactor
2. No system crontab entry was created as a replacement
3. No OpenClaw cron job was set up
4. The engine code itself was fine — last successful runs were May 27-28 (drafts #906, #922)
5. A previous FATAL crash on May 23 ("Cannot read properties of undefined (reading 'passed')") was caused by `judgeAllReady()` throwing an unhandled error, but this was in an older code version and had been fixed by May 27

The DB continued to be modified (last: Jul 30) because `slack-review.js watch` runs during heartbeats, masking the fact that the generation pipeline was completely idle.

#### Code Fixes

**1. Resilient QA Judge error handling**
```javascript
// Before: crash if judgeAllReady() throws
results.review = await judgeAllReady() || { passed: 0, rejected: 0 };

// After: graceful degradation
try {
  results.review = await judgeAllReady() || { passed: 0, rejected: 0 };
} catch (e) {
  log(`  ⚠️ QA Judge failed: ${e.message?.slice(0, 200)}`);
  results.review = { passed: 0, rejected: 0 };
}
```

**2. Resilient summary output**
```javascript
// Before: crash if results.review is undefined
log(`  Review: ${results.review.passed} passed, ...`);

// After: safe access with fallback
const review = results.review || { passed: 0, rejected: 0 };
log(`  Review: ${review.passed || 0} passed, ...`);
```
